# Date Fruit Classification

Classifies Date Fruit varieties using an Artificial Neural Network (ANN) Classification.

## Dataset
DateFruit_Dataset.csv - Date fruit image features dataset
- Features: Area, Perimeter, Major Axis, Minor Axis, Eccentricity, etc.
- Target: Class (Date Fruit Variety - 7 classes)

## Workflow in this notebook
1. Data Loading & Visualization
2. Data Preprocessing - Label Encoding & Feature Scaling
3. Train-Test Split
4. Model - Artificial Neural Network (ANN) Classification
5. Prediction & Evaluation (Accuracy, Confusion Matrix, Classification Report)

## Tech Stack
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn, TensorFlow / Keras

## How to Run
pip install pandas numpy matplotlib scikit-learn tensorflow
jupyter notebook ANN_Classification.ipynb
